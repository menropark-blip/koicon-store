# KOICON 코이콘

Montage의 캐릭터 굿즈 스토어입니다.

HTML, CSS, JavaScript로 구현한 GitHub Pages 사이트이며 Firebase Authentication과 Firestore를 연결합니다. 무료 플랜의 구매 문의 방식으로 운영합니다. 온라인 결제와 자동 재고 차감은 제공하지 않습니다.

`index.html` 페이지 구조, `style.css` 디자인, `app.js` 화면 동작, `firebase-service.js` 서버 연결, `config.js` 공개 Firebase 웹 설정입니다.

상품은 제공된 굿즈 이미지에 맞춘 판매 준비 컬렉션입니다. 가격과 사양은 작가에게 문의해주세요.
